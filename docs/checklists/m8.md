# M8 checklist — MIDI out, file I/O, automation

Sign-off by the owner (PLAN.md §9, M8). Automated facts are in PLAN.md (M8 status): loopback
jitter 0.063 ms, bit-identical renders, SMF cross-checked with libremidi's reader.

Setup: `NEW FUTURE-FUNK` (or your own project). MIDI out is off by default: Page 3, PAGE DOWN (or
`P3 OUT`), MIDI OUT = ON, switch your synth's output ON (and CLOCK ON for a sequencer or drum
machine). Choose per track DEST / PORT / CH / PROG in the TRACKS table.
